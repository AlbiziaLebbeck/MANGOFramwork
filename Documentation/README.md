The migration plan is a historical proposal. Use the getting-started, build/runtime, and validation guides for the delivered behavior. Shared evidence under [Validation/](Validation/) includes build manifests, browser results, and screenshots from the compiled Client. The screenshot guest is **PoppyValidation**; this is test data, not a fixed account or default player name.

แผน migration เก็บข้อเสนอเดิมไว้เป็นประวัติ ให้ใช้คู่มือใช้งาน รายละเอียด Build/runtime และผลตรวจสำหรับพฤติกรรมรุ่นปัจจุบัน หลักฐานร่วมใน [Validation/](Validation/) ประกอบด้วย manifest, ผล browser และภาพจาก Client ที่ Build จริง ชื่อ guest ในภาพคือ **PoppyValidation** เป็นข้อมูลทดสอบ ไม่ใช่บัญชีหรือชื่อผู้เล่นเริ่มต้นที่บังคับใช้

When changing behavior or limitations, update both language versions and keep the language links working. Code identifiers, menu names, commands, version numbers, and paths remain unchanged between translations.
